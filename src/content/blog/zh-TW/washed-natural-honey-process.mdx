## 咖啡豆其實是種子

我們買到的咖啡豆，是咖啡果實內的種子。一顆成熟的咖啡果實（常稱為「咖啡櫻桃」）由外到內大致有：果皮、果肉、黏稠的果膠層、羊皮層、銀皮，最後才是種子。

採收後，生產者需要移除或乾燥這些外層，並把種子的含水量降至適合儲存和運輸的水平。**處理法描述的就是這段流程**，它會影響最終風味，但不是對味道的保證。

## 三種最常見的處理法

### 水洗處理（Washed）

1. 去除果皮和大部分果肉。
2. 種子連同果膠層在水槽或乾燥環境中發酵，令果膠分解。
3. 用水清洗掉殘餘果膠。
4. 乾燥帶羊皮層的種子。

水洗處理常被描述為輪廓清楚、酸質明亮、乾淨度高，因為果實成分對種子的影響較少。但產區、品種、發酵時間和烘焙仍會大大改變結果。

### 日曬處理（Natural）

1. 整顆果實不去皮，直接放在曬床或架高的棚架上乾燥。
2. 期間需要定時翻動，並在下雨時遮蓋。
3. 乾燥完成後，才一次過去除乾掉的果皮與果肉。

National Coffee Association 指出，成熟度一致與乾燥管理對日曬品質非常重要。日曬豆常被描述為果香濃郁、甜感明顯、口感較厚，但只看「日曬」二字，不能推斷一定有某種水果味。處理不當時，也可能帶來過度發酵或泥土味。

### 蜜處理／半水洗（Honey / Pulped Natural）

介乎上述兩者之間：先去除果皮和果肉，但保留不同比例的果膠層一同乾燥。

| 名稱 | 一般理解 |
| --- | --- |
| 白蜜／黃蜜 | 保留較少果膠，乾燥較快 |
| 紅蜜 | 保留中等果膠 |
| 黑蜜 | 保留較多果膠，乾燥較慢 |

這些名稱在不同產地的用法未必一致，有時指保留的果膠比例，有時指乾燥時的遮光程度。所以應查看烘焙商或生產者提供的實際流程，而不是只看顏色名稱。

## 三種處理法的比較

| | 水洗 | 蜜處理 | 日曬 |
| --- | --- | --- | --- |
| 去除果肉 | 乾燥前 | 乾燥前（保留部分果膠） | 乾燥後 |
| 用水量 | 較多 | 較少 | 最少 |
| 常見描述 | 乾淨、明亮 | 甜感、平衡 | 果香、厚實 |
| 主要風險 | 發酵控制 | 乾燥時發霉 | 乾燥不均、過度發酵 |

「常見描述」只是一般傾向，個別批次可以有很大差異。

## 其他你可能見到的名稱

近年市場上出現不少實驗性處理法，例如：

- **厭氧發酵（Anaerobic）**：在密封、低氧環境中發酵，風味常較強烈和獨特。
- **二氧化碳浸漬（Carbonic Maceration）**：借用葡萄酒釀造的概念，在充滿二氧化碳的容器中發酵。
- **濕剝（Wet-hulled / Giling Basah）**：常見於印尼，在種子仍然較濕時去除羊皮層，風味常帶草本或泥土感。

這些名稱的實際做法差異很大，最好閱讀烘焙商提供的說明。

## 如何轉化成沖煮測試

1. **先用你的基準配方**：相同粉水比與水溫，避免一開始便因標籤預設結果。
2. **果香強烈的日曬或厭氧豆**：若味道過於濃烈或帶發酵感，可先減少攪動，觀察乾淨度與餘韻是否改善。
3. **水洗豆酸質尖而薄**：先把研磨調細一小格，而不是直接把水溫大幅降低。
4. **蜜處理豆**：通常可以從基準配方開始，再按味道微調。
5. **記錄實際喝到的味道**：不要把處理法當成固定的風味分類。

## 閱讀包裝標籤

一個資料齊全的標籤，通常包括：

| 資料 | 告訴你甚麼 |
| --- | --- |
| 國家／產區／莊園 | 風土和栽種環境 |
| 品種 | 例如 Typica、Bourbon、Geisha，影響風味潛力 |
| 海拔 | 高海拔常與較緻密的豆有關 |
| 處理法 | 本文討論的內容 |
| 採收期 | 判斷生豆是否新鮮 |
| 烘焙日 | 判斷熟豆狀態和養豆時間 |
| 風味描述 | 烘焙商的品嚐筆記，作參考用 |

若只寫「日曬」而沒有其他資料，它只能作粗略起點。建立自己的沖煮紀錄，才能知道同一處理法在不同豆款上是否真的有一致表現。

## 一個簡單的比較練習

如果你想親身感受處理法的差異，可以嘗試：

1. 找同一產區（最好同一莊園）的水洗與日曬豆，很多烘焙商會以套裝形式出售。
2. 用完全相同的配方沖煮。
3. 降溫後並排品嚐，記錄香氣、酸質、甜感、口感和餘韻。

這種「只改一個變數」的比較，比閱讀任何文章都更能幫你建立味覺參考。

## 常見問題

**哪一種處理法最好？**
沒有最好，只有是否符合你的口味。喜歡乾淨明亮的人可能偏好水洗，喜歡濃郁果香的人可能偏好日曬。

**日曬豆是否較容易有瑕疵？**
日曬處理對乾燥管理要求高，處理不當時較易出現過度發酵等問題。但優質的日曬豆同樣可以非常乾淨。

**處理法會影響保存嗎？**
熟豆的保存方法大致相同：避開氧氣、濕氣、熱與光。處理法主要影響風味，而不是保存要求。
