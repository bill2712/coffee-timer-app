## 先學會描述你喝到甚麼

「這杯不好喝」很難幫你改善下一杯。要修正問題，先要把感受拆開。品嚐時，試著分別回答：

1. **酸質**：清楚明亮，還是尖銳刺激？
2. **甜感**：有沒有？出現在入口、中段還是餘韻？
3. **苦味**：像黑朱古力一樣圓潤，還是像焦炭一樣刺口？
4. **口感**：像水一樣稀，還是厚實、有重量？
5. **餘韻**：吞下後味道停留多久？是舒服的甜，還是乾澀、刮喉？

咖啡降至溫熱時再喝。太燙時舌頭對酸和甜都不敏感，很多問題要待溫度下降才會出現。

## 好的酸與壞的酸

很多新手一喝到酸便認為沖壞了。其實酸質是精品咖啡的重要特徵，特別是淺焙咖啡。關鍵在於分辨：

| | 好的酸質 | 萃取不足的酸 |
| --- | --- | --- |
| 感覺 | 明亮、有果汁感 | 尖銳、刺激、像未熟 |
| 伴隨 | 有甜感支撐 | 沒有甜感，口感空洞 |
| 餘韻 | 乾淨、愉快 | 短促，有時帶鹹 |
| 例子 | 像柑橘、莓果 | 像醋、未熟水果 |

如果酸質讓你想再喝一口，它多半是好的酸；如果它讓你皺眉，便可能需要增加萃取。

## 烘焙的苦與萃取過度的苦

苦味也不一定是錯。深焙咖啡本來就有較多苦味，這是烘焙風格的一部分。

| | 烘焙帶來的苦 | 萃取過度的苦 |
| --- | --- | --- |
| 感覺 | 圓潤，像可可、焦糖 | 刺口、粗糙 |
| 伴隨 | 常有甜感 | 常伴隨乾澀、收斂感 |
| 餘韻 | 苦甜平衡 | 乾口、刮喉、久久不散 |

「乾澀」是判斷萃取過度最有用的線索：喝完後口腔像被吸乾、舌頭兩側發緊，便要考慮減少萃取。

## 八種常見問題與修正方向

| 你喝到 | 較可能的原因 | 下一杯只改這一項 |
| --- | --- | --- |
| 尖酸、薄、短促 | 萃取不足 | 研磨調細一小格 |
| 苦、乾澀、尾段很慢 | 萃取過度或細粉堵塞 | 研磨調粗一小格 |
| 平衡但像水 | 濃度太低 | 粉水比改濃（例如 1:16 → 1:15） |
| 厚重、壓迫，但不苦不澀 | 濃度太高 | 粉水比改稀（例如 1:15 → 1:16） |
| 同一杯又酸又澀 | 流動不均、偏流 | 減少攪動，檢查注水是否集中一點 |
| 平淡、香氣很弱 | 豆不新鮮或保存不當 | 檢查烘焙日和保存方法 |
| 有紙味 | 濾紙未預濕 | 用熱水充分沖洗濾紙 |
| 帶鹹、怪味 | 水質或萃取嚴重不足 | 先換水比較，再調研磨 |

### 為何先改研磨？

研磨對萃取影響最直接，也最容易回復。改研磨一小格，下一杯便能看到方向是否正確。水溫和注水手法的影響較難單獨判斷，留待研磨方向清楚後才調整。

## 一個完整的修正例子

**情況**：一包中焙哥倫比亞豆，15 g、240 g 水、92°C，2:30 完成。味道尖酸、口感薄。

1. **診斷**：尖酸而薄，流速偏快，傾向萃取不足。
2. **第二杯**：只把研磨調細一小格。結果 2:50 完成，酸質柔和了，開始有焦糖甜感。
3. **第三杯**：維持設定重複一次，結果相近，確認改動有效。
4. **第四杯**：味道平衡，但覺得略稀，把粉水比改為 1:15。
5. **結論**：保留細一格研磨與 1:15，作為這包豆的基準。

整個過程只用了四杯，而且每一步都知道為甚麼。

## 「又酸又苦」最容易誤判

當一杯咖啡同時尖酸又乾澀，很多人會把研磨調來調去，結果越調越亂。這種情況通常不是整體萃取太多或太少，而是**萃取不均勻**：部分咖啡粉沒被水充分接觸，部分則被過度萃取。

常見原因：

- 悶蒸時有乾粉未被濕透；
- 水柱太集中在中心或太靠近濾紙；
- 旋轉或攪拌過度，細粉堵塞濾紙；
- 濾杯沒有放平；
- 使用砍豆機，粗細差異太大。

先改善這些操作問題，再回頭調整研磨。

## 不要忽略咖啡豆本身

有些「問題」其實來自咖啡豆，而不是沖煮：

- **過期或保存不當的豆**：香氣弱、平淡，怎樣調也難救回。
- **剛烘焙的豆**：排氣多，流速和味道每天都在變。
- **風格本身**：深焙豆就是會苦，淺焙豆就是會酸。如果這不是你喜歡的風格，換豆可能比調配方更有效。

## 常見問題

**加糖加奶可以解決酸或苦嗎？**
可以掩蓋，但不會解決萃取問題。如果你喜歡加奶，可以先沖出平衡的咖啡，再按口味加入。

**怎樣訓練自己分辨味道？**
並排比較最有效：同一包豆，一杯研磨細一點、一杯粗一點，同時品嚐。差異放在一起時會清楚得多。

**每次都要寫筆記嗎？**
開新豆的頭幾杯最好記錄。找到基準後，只需在味道明顯改變時再記下。
