私隱政策

更新日期：2026 年 8 月 30 日

本政策說明當你使用 Barista Flow 時，哪些資料會留在瀏覽器、哪些第三方資源可能收到一般網絡請求，以及你可以如何控制或刪除資料。

1. 不設帳戶，也不收集表單資料

網站不提供註冊或登入，也沒有把聯絡表單送到伺服器。問題回報會連到 GitHub；你在 GitHub 提交的內容受 GitHub 自身的條款與私隱政策規管。請勿在公開 Issues 張貼個人或敏感資料。

2. 只在本機儲存的資料

咖啡配方、沖煮紀錄、靜音設定、語言偏好和 PWA 提示狀態使用瀏覽器 localStorage 儲存在你的裝置。Barista Flow 不會把這些資料上傳到自己的伺服器。清除本網站的瀏覽資料即可刪除。

3. 分享連結

當你主動使用「分享配方」時，咖啡豆名稱和沖煮參數會寫入網址查詢字串，方便另一部裝置讀取。連結不會自動送出，但任何收到連結的人都能看到其中的參數，因此請勿在咖啡豆名稱輸入個人資料。

4. 第三方網絡請求

頁面會從 Google Fonts 下載字型，計時圖表會從 jsDelivr 取得 Chart.js。網站亦保留 Google AdSense 的站點驗證程式供審核；即使目前沒有顯示廣告，第三方仍可能收到 IP 位址、瀏覽器類型、請求時間和來源頁等標準技術資料。請參閱相應供應商的私隱政策。

5. 分析與廣告狀態

網站目前沒有載入 Google Analytics，亦沒有顯示廣告單元。若日後啟用 AdSense，會在適用地區先配置 Google 認證的同意管理平台，並更新本政策和頁面上的披露。

6. 保安與資料保留

網站是靜態頁面，沒有 Barista Flow 使用者資料庫。公開原始碼及修正紀錄可供檢視；安全問題應使用 GitHub 的私密漏洞回報，而不是公開 Issue。

7. 聯絡

如對本政策有疑問，請使用「聯絡與回報問題」頁面的公開或私密回報渠道。
