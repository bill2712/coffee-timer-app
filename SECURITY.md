# Security policy

## Supported version

The current production version on the `main` branch is supported.

## Report a vulnerability privately

Please use GitHub's [private vulnerability reporting](https://github.com/bill2712/coffee-timer-app/security/advisories/new). Do not include exploit details, credentials, personal data, or other sensitive information in a public issue.

Include:

- the affected URL or file;
- clear reproduction steps;
- the security impact;
- browser and operating-system details when relevant;
- a minimal proof of concept, without accessing data that does not belong to you.

The maintainer will acknowledge the report in GitHub, investigate it, and publish a fix before public disclosure when the issue is confirmed.
